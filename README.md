# CineSwipe (Локальная версия)

Приложение, которое помогает выбрать фильм на вечер за пару минут. Вместо бесконечного скролла каталога вы свайпаете карточки, а приложение подстраивает подборки под ваш вкус. Учебный проект: Android-приложение на Kotlin с общей логикой в модуле Kotlin Multiplatform.

## Идея приложения

Свайп-экран строится вокруг четырёх жестов и шкалы оценки под постером:

| Жест | Действие |
|---|---|
| Вправо | Хочу посмотреть |
| Влево | Не хочу |
| Вверх | Очень хочу (приоритет) |
| Вниз | Уже смотрел, без оценки |
| Шкала под постером | Уже смотрел, с оценкой от «ужасно» до «отлично» |

Все действия можно отменить. Рекомендации строятся по вашим свайпам без машинного обучения: по ним собирается профиль вкуса, из TMDB подбираются кандидаты, и каждый получает оценку по прозрачной формуле с пояснением вида «Потому что вам понравился X».

Планируются также подборки, поиск, фильтры, списки «Хочу» и «Просмотрено» и информация о том, где смотреть фильм в выбранном регионе.

| Область | Решение |
|---|---|

| UI | Jetpack Compose, Navigation Compose с типобезопасными маршрутами, Material 3 |
| Сеть | Ktor Client, kotlinx.serialization |
| База данных | Room (KMP) — с этапа 3 |
| DI | Koin |
| Асинхронность | Coroutines, Flow |
| Логирование | Napier |
| Тесты | kotlin.test, Ktor MockEngine, kotlinx-coroutines-test, Turbine |
