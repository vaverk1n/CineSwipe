## 1. Принципы

1. **Жесты важнее кнопок.** Основное действие — движение карточки; интерфейс вокруг почти не мешает.
2. **Контент в центре.** Постер — самый яркий элемент экрана, всё остальное тёмное и приглушённое.
3. **Цвет несёт смысл.** Зелёный — хочу, красный — не хочу, золотой — очень хочу, синий — смотрел. Цвет всегда дублируется текстом или иконкой.
4. **Один набор токенов.** Ни один экран не содержит захардкоженных цветов, размеров и шрифтов.
5. **Каждое состояние нарисовано.** Loading, Error, Empty и Offline есть у каждого экрана, а не только Content.

## 2. Токены

### 2.1 Цвета

Основная тема тёмная. Светлая тема — необязательная (FR-13).

| Токен | HEX | Назначение |
|---|---|---|
| `background` | `#0A0A12` | Фон экранов |
| `onBackground` | `#F3F3FA` | Основной текст |
| `onBackgroundMuted` | `#B4B4CC` | Подписи, неактивные элементы |
| `onBackgroundSoft` | `#D6D6EE` | Вторичный текст (подсказки, пояснения) |
| `primary` | `#E8A2FF` | Акцент: активная вкладка, ссылки, иконки действий |
| `want` | `#2FBF7A` | «Хочу», положительная оценка |
| `wantStamp` | `#7DE3A6` | Штамп «ХОЧУ» на тёмной подложке |
| `nope` | `#FF8A8A` | «Не хочу», ошибки, удаление |
| `veryWant` | `#F3D27A` | «Очень хочу», приоритет |
| `watched` | `#7FB0E0` | «Смотрел» |
| `surfaceOverlay` | `rgba(255,255,255,.10)` | Плашки, разделители, неактивные кнопки |
| `navBar` | `rgba(10,10,18,.85)` | Нижняя панель навигации |
| `scrim` | градиент от прозрачного к `rgba(10,10,20,.90)` | Подложка текста поверх постера |

**Цвета шкалы оценки**

| Деление | Подпись | HEX |
|---|---|---|
| −2 | Ужасно | `#FF6B6B` |
| −1 | Плохо | `#FFA45C` |
| 0 | Нормально | `#C9C9D8` |
| +1 | Хорошо | `#8BD97F` |
| +2 | Отлично | `#2FBF7A` |

**Оттенки состояний жеста (накладываются на карточку)**

| Жест | Оттенок | Свечение края экрана |
|---|---|---|
| Вправо | `rgba(30,170,100,.28)` | справа, `rgba(47,191,122,.5)` |
| Влево | `rgba(220,50,60,.30)` | слева, `rgba(255,70,80,.5)` |
| Вверх | `rgba(243,210,122,.25)` | сверху, `rgba(243,210,122,.4)` |
| Вниз | `rgba(80,140,230,.30)` | снизу, `rgba(80,140,230,.45)` |

**Фон-ambient (вариант G):** два размытых радиальных пятна поверх `background`:
`rgba(90,70,220,.45)` с центром в 15% / 12% и `rgba(224,122,95,.40)` с центром в 88% / 72%, радиус затухания 55%.
В итоговой версии цвета пятен можно брать из доминирующих цветов текущего постера (Palette API / Coil).

> Требование к контрасту: основной текст не менее 4,5 : 1 к фону. Проверить значения инструментом контраста после замены токенов значениями из макета.

### 2.2 Типографика

Шрифт: **Manrope** (лицензия SIL OFL), начертания 500 / 600 / 700 / 800. Запасной: системный sans-serif.
Подключение: файлы в `res/font` (надёжнее для офлайна) или downloadable fonts.

| Роль | Размер | Начертание | Трекинг | Где используется |
|---|---|---|---|---|
| `headline` | 28 sp | 800 | −1 sp | Название фильма на карточке |
| `title` | 20 sp | 800 | −0.5 sp | Заголовки экранов и секций |
| `stamp` | 30 sp | 800 | 0 | Штампы «ХОЧУ», «НЕТ» и другие |
| `body` | 14 sp | 600 | 0 | Мета-строка, описания |
| `bodyStrong` | 14 sp | 700 | 0 | Счётчик «8 из 20», кнопки-ссылки |
| `caption` | 13 sp | 600 | 0 | Подсказка над шкалой, пояснения |
| `label` | 12 sp | 600 (активное 800) | 0 | Подписи делений шкалы и жестов, вкладки |

Минимальный размер текста в приложении — 12 sp. Для пользователей с увеличенным шрифтом тексты не обрезаются: названия фильмов ограничены `maxLines = 2` с многоточием.

### 2.4 Тени и слои

| Элемент | Параметры |
|---|---|
| Карточка свайпа | тень 0 / 30 / 60 dp, `rgba(0,0,0,.6)` |
| Ползунок шкалы | тень 0 / 4 / 12 dp, `rgba(0,0,0,.5)` |
| Порядок слоёв, снизу вверх | фон-ambient → свечение края → карточка → оттенок и штамп → панели → подсказка первого запуска |

### 2.5 Движение

| Событие | Параметры |
|---|---|
| Улёт карточки после жеста | 250 мс, ease-out |
| Возврат карточки при недоборе порога | пружина (`spring`, умеренная жёсткость) |
| Наклон карточки | пропорционален смещению по X, максимум ±12° |
| Прозрачность штампа | растёт с 0 до 1 пропорционально прохождению порога |
| Пауза после выбора оценки | 0,6 с, полоска таймера на плашке |
| Уход карточки после оценки | вниз с затуханием, 250 мс |
| Вибрация | короткая: на пороге жеста и на каждом делении шкалы |

## 3. Экраны

Нижняя навигация из четырёх вкладок: **Свайп**, **Подборки**, **Списки**, **Ещё**. Детали фильма открываются поверх вкладок. Онбординг показывается один раз.

### 3.1 Свайп (главный экран, вариант G)

Сверху вниз:

1. **Верхняя панель:** счётчик «8 из 20» слева (`bodyStrong`), кнопка «Отменить» справа (иконка 44 dp на полупрозрачной подложке).
2. **Карточка** 300 × 462 dp по центру: постер, внизу подложка `scrim` с названием (`headline`) и мета-строкой «2014 · ★ 8.6 · 2 ч 49 мин».
3. **Шкала оценки** под карточкой: подпись «Уже смотрели? Сдвиньте шкалу, чтобы оценить» (`caption`), трек с пятью точками, ползунок по центру серым, подписи делений (`label`).
4. **Подсказки жестов:** четыре круга с подписями «Не хочу», «Очень хочу», «Смотрел», «Хочу». Они не нажимаются, это только напоминание; активная при жесте заливается своим цветом.
5. **Нижняя навигация.**

Состояния: покой, вправо, влево, вверх, вниз, выбор оценки, Loading (скелетон карточки), Error (Snackbar или ErrorView), Empty («Фильмы закончились» + «Изменить фильтры»), Offline (баннер сверху).
Прототип всех шести жестовых состояний: холст G1–G6 (ссылка выше).

### 3.2 Онбординг (4 шага)

Сверху индикатор из 4 сегментов. Шаг 1 — регион и язык; шаг 2 — жанры чипами (минимум 3); шаг 3 — сетка постеров 3 × 4 (тап = «хочу»); шаг 4 — стриминговые сервисы региона (можно пропустить). Внизу кнопка «Далее» во всю ширину, неактивна, пока условие шага не выполнено. Финал — подсказка жестов (см. 5.3).

### 3.3 Детали фильма

Бэкдроп 16 : 9 с градиентом, круглая кнопка «назад», кнопка ▶ «Трейлер» по центру. Ниже: название, «2014 · 2 ч 49 мин · ★ 8.6», чипы жанров, кнопки «Хочу» и «Просмотрено» (последняя открывает ту же шкалу оценки в нижней панели), описание (4 строки + «Ещё»), «В ролях» (круглые фото), «Где смотреть» (группы «Подписка / Аренда / Покупка»), «Похожие фильмы».

### 3.4 Подборки

Поисковая строка и кнопка фильтров, ряд жанров-чипов, секции с горизонтальными рядами постеров 140 × 210 dp («Для вас», «Популярное», «Топ рейтинга», «Сейчас в кино», «Тренды»). У секции кнопка «Все →» открывает сетку из трёх колонок. Фильтры — в нижней панели: жанры, годы, рейтинг, длительность, язык, «Только на моих сервисах».

### 3.5 Списки

Два таба: «Хочу (N)» и «Просмотрено (N)». Строка: миниатюра 80 × 120 dp, название, мета-строка, чипы сервисов («Хочу») или подпись оценки с цветной точкой («Просмотрено»; без оценки — кнопка «Оценить»). Фильмы «очень хочу» отмечены значком `veryWant` и идут первыми. Свайп влево по строке — «Удалить» (цвет `nope`) и Snackbar «Отменить».

### 3.6 Ещё (настройки)

Регион и язык, сервисы, «Показать подсказки жестов», «Сбросить профиль вкуса», «О приложении» (атрибуция TMDB). В debug-сборке дополнительно «Для разработчиков».

### 3.7 Панель разработчика (только debug)

Карточка с версией, номером сборки, хешем коммита, регионом и языком; переключатели «Нет сети», «Медленная сеть (+3 с)», «Ответ 500», «Пустой ответ»; окно лога (моноширинный шрифт, ошибки цветом `nope`); кнопки «Скопировать лог для баг-репорта» и «Сбросить кеш и профиль».

## 5. Жесты свайп-экрана

### 5.1 Спецификация

| Жест | Порог срабатывания | Действие | Запись (`SwipeAction`) | Вес в профиле |
|---|---|---|---|---|
| Вправо | смещение > 35% ширины или скорость > 1000 dp/с | Хочу | `WANT` | +1,0 |
| Влево | то же | Не хочу | `NOPE` | −0,5 |
| Вверх | смещение > 25% высоты | Очень хочу | `VERY_WANT` | +2,0 |
| Вниз | смещение > 25% высоты | Смотрел без оценки | `WATCHED` | 0 |
| Ползунок шкалы | отпускание на делении ≠ центр | Смотрел с оценкой | `WATCHED` + рейтинг | −2…+2 |

Недобор порога: карточка пружинно возвращается на место, событие не записывается.

### 5.2 Правила распознавания

- **Блокировка оси.** Направление определяется по первым 12 dp движения и не меняется до отпускания; диагональный жест не срабатывает случайно.
- **Шкала независима от карточки.** Жест, начатый на шкале, карточка не получает.
- **Центр шкалы.** Смещение в центр оценку не ставит. «Нормально» ставится тапом по центральной точке.
- **Пауза.** После выбора оценки 0,6 с горит плашка «В "Просмотрено" · оценка: хорошо» с кнопкой «Отменить»; без отмены оценка сохраняется и карточка уходит вниз.
- **Отмена** (иконка сверху) возвращает последнюю карточку, до 10 шагов, и удаляет событие вместе с оценкой.

### 5.3 Подсказка при первом запуске

Затемнение экрана, четыре стрелки с подписями («Влево — не хочу», «Вправо — хочу», «Вверх — очень хочу», «Вниз — смотрел») и подсказка про шкалу. Закрывается тапом, показывается один раз, повторить можно в «Ещё → Показать подсказки».

## 7. Доступность

- Размер области нажатия не менее 48 × 48 dp, даже если иконка меньше.
- У карточки семантические действия для TalkBack: «Хочу», «Не хочу», «Очень хочу», «Смотрел»; без них жестовый экран недоступен.
- Шкала сообщает своё состояние («Оценка: хорошо» или «Оценка не выбрана») и управляется кнопками громкости и жестами TalkBack.
- У всех иконок есть `contentDescription`; штампы и подсказки не полагаются только на цвет.
- Анимации учитывают системную настройку «Убрать анимацию»: вместо улёта карточка просто исчезает.
- Контраст текста не менее 4,5 : 1; цветные подписи делений шкалы дублируются текстом.

## 8. Перенос в Compose

Структура: `androidApp/ui/theme/` — `Color.kt`, `Type.kt`, `Shape.kt`, `Spacing.kt`, `Theme.kt`.

```kotlin
// Color.kt
object CineColors {
    val Background = Color(0xFF0A0A12)
    val OnBackground = Color(0xFFF3F3FA)
    val OnBackgroundMuted = Color(0xFFB4B4CC)
    val Primary = Color(0xFFE8A2FF)
    val Want = Color(0xFF2FBF7A)
    val Nope = Color(0xFFFF8A8A)
    val VeryWant = Color(0xFFF3D27A)
    val Watched = Color(0xFF7FB0E0)
}

val RatingColors = listOf(
    Color(0xFFFF6B6B), Color(0xFFFFA45C), Color(0xFFC9C9D8),
    Color(0xFF8BD97F), Color(0xFF2FBF7A),
)

// Spacing.kt
object Spacing { val xs = 4.dp; val s = 8.dp; val m = 12.dp; val l = 16.dp; val xl = 24.dp }

// Type.kt (фрагмент)
val Headline = TextStyle(fontFamily = Manrope, fontWeight = FontWeight.ExtraBold,
    fontSize = 28.sp, letterSpacing = (-1).sp)
```

Правило: экраны обращаются только к `MaterialTheme` / `CineColors` / `Spacing`; литералы `Color(...)` и `.dp` с «магическими числами» в экранах запрещены (проверка при самопроверке Pull Request).

## 10. Открытые вопросы

1. Выбрать Figma-макет и заменить токены из прототипа значениями из макета (раздел 2).
2. Решить, нужна ли светлая тема (FR-13).
3. Подключать Manrope файлами в `res/font` или через downloadable fonts.
4. Брать ли цвета ambient-фона из постера (Palette API) или оставить фиксированными.
5. Нужен ли переключатель «Показывать кнопки действий» для пользователей, которым неудобны жесты.
